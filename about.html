Latest project

Quno: an offline AI on an Arduino UNO Q

An Arduino UNO Q that runs its own language model (llama3.2:3b through Ollama) with no internet. Plug it into any computer with a USB cable, type one ssh command, and chat with it. The built-in LED matrix shows a face for ready, thinking and error. Read the full build log.
